문의할 때

앱 버전, 기기 모델, 문제가 발생한 화면과 상황을 알려 주세요. 비밀번호나 인증 토큰은 보내지 마세요.

저장과 초기화

별도 로그인 없이 익명 식별자로 진행도를 저장합니다. 기기에 자동 저장하고 서버 연결 시 동기화합니다. 다른 기기로의 계정 이전은 지원하지 않습니다. 설정의 저장 데이터 초기화는 진행도를 처음 상태로 바꾸며, 서버 연결 시 같은 식별자의 저장에도 반영됩니다. 앱 삭제만으로 서버 데이터가 삭제되지는 않습니다.

서버 데이터 삭제 문의

서버 데이터 삭제를 원하면 문의 이메일로 요청해 주세요. 해당 저장 데이터의 이용자인지 확인하는 데 필요한 최소한의 정보를 안내합니다. 저장 데이터 초기화와 서버 식별자 삭제는 서로 다릅니다.

광고가 나오지 않나요?

보상형 광고는 직접 선택한 경우에 이용하며, 광고 제공 여부와 일일 횟수 제한이 적용됩니다. 광고 재고 부족, 취소, 중단, 오류 때는 보상을 지급하지 않습니다. 잠시 뒤 다시 시도하고 문제가 계속되면 문의해 주세요.
