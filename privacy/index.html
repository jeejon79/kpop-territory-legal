Firebase 익명 인증에 사용하는 익명 사용자 식별자와 인증 정보, 기기/설치에 연결된 식별자, 아이돌 영입·성장, 재화, 스테이지 진행·기록, 설정, 광고 보상 지급 기록과 관련 시각을 처리합니다. 게임 시작을 위해 이름, 전화번호, 이메일 입력을 요구하지 않습니다. 문의 시에는 이용자가 보낸 이메일과 문의 내용을 처리합니다. 선택적 후원 결제는 Apple이 처리합니다. 앱은 Apple이 제공한 상품 및 거래 정보를 기기에서 확인하며, 카드나 은행 계좌 정보는 받지 않습니다. 후원 거래를 게임 저장 서버로 전송하지 않습니다.

3. 목적과 외부 서비스

게임 진행 저장·동기화, 보상 지급과 중복 지급 방지, 서비스 보안, 문의 대응에 사용합니다. Firebase는 익명 인증을, Supabase는 익명 식별자에 연결된 게임 데이터 저장을 제공합니다. Google Mobile Ads와 UMP는 선택형 광고, 광고 성과 측정, 오류 진단 및 동의 관리를 위해 IP 기반 대략적 위치, 기기 식별자, 광고·앱 상호작용, 성능·진단 정보와 동의 선택을 처리할 수 있습니다.

Google Analytics for Firebase는 이용 흐름과 게임 개선을 위해 화면 이동, 스테이지 시작·완료·실패, 광고 결과, 앱 사용 시간, 기기·운영체제·앱 버전, 앱 인스턴스 또는 브라우저 식별자 및 IP에서 파생된 대략적 지역을 처리합니다. iOS에서는 상품 ID·가격 등 인앱 구매 이벤트가 자동 측정될 수 있습니다. 분석 이벤트에 Firebase 인증 ID, 토스 계정 키, 이름·이메일 또는 저장 데이터 원문을 포함하지 않습니다. 분석의 광고 개인화와 Google 신호는 사용하지 않습니다. Sentry는 오류 분류·발생 위치·앱 버전·플랫폼·운영체제 정보를 처리하며 사용자 저장 원문이나 인증 정보를 전송하지 않도록 제한합니다. 앱인토스에서는 토스가 제공한 식별자로 저장 기능을 연결하고 토스 및 연결 광고 사업자가 광고 요청·보상 결과를 처리합니다.

4. 보관과 삭제

게임 데이터는 서비스 제공과 보안에 필요한 기간 보관하며, 더 이상 필요하지 않거나 유효한 삭제 요청을 처리한 경우 삭제 또는 비식별화합니다. 법령상 보관 의무가 있는 경우 해당 기간 보관합니다. 초기화는 진행도를 처음 상태로 바꾸는 기능이며 익명 서버 식별자의 완전 삭제가 아닙니다. 앱 삭제만으로 서버 저장이 삭제되지 않으므로 서버 데이터 삭제는 문의 이메일로 요청해 주세요.
